# Native header branding

`moflight-ai-logo-dark.png` is an unchanged copy of Manuel's approved dark Thermik logo from `docs/assets/branding/moflight-ai-logo-dark.png`. The native fixed header displays the full square artwork with its original aspect ratio. This is approved project artwork covered by the repository license; it does not indicate that cloud AI is connected. No logo redesign or background removal was performed.

`../icons/aircraft-side.svg` is the selected side-view B master for the transparent `aircraft-side.png` used in current navigation, tinted by active state. The previous `aircraft.svg` / `aircraft.png` remain retained assets. Profile/book/Medical marks are native code shapes. Current meanings, visual rules and editable sources are centralized in the [UI design handbook](../../../../docs/product/design/README.md); no icon runtime dependency was added.
