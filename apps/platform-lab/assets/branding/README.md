# Native header branding

`moflight-ai-logo-dark.png` is an unchanged copy of Manuel's approved dark Thermik logo from `docs/assets/branding/moflight-ai-logo-dark.png`. The native fixed header displays the full square artwork with its original aspect ratio. This is approved project artwork covered by the repository license; it does not indicate that cloud AI is connected. No logo redesign or background removal was performed.

The default Modern Duotone family uses local PNGs in `../icons/duotone/`, including the folded paper plane for Flüge and M2 Medical card. Superseded aircraft assets have been removed. The [symbol library](../../../../docs/product/design/symbols/README.md) records editable SVG sources and regeneration; the [UI design handbook](../../../../docs/product/design/README.md) controls visual rules. Approved Thermik branding is preserved; no icon runtime dependency was added.
