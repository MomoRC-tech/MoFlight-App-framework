# MoFlight logo assets

Manuel selected the **Thermik** concept and approved these light and dark revisions on 2026-10-13. The glider and rising thermal curve retain the flying identity; the sparkles and explicit **AI** badge identify the planned AI-assisted functionality. The project name remains **MoFlight**; the proposed joined name `MoFlightAI` was discarded.

These are the original approved AI-generated PNGs, copied without modification. They have opaque backgrounds and are raster artwork, not SVG masters or production Android/iOS icon exports. The root README selects the matching logo for the viewer's color scheme. The earlier `../moflight-logo.svg` remains available as a historical provisional asset.

The original app icon is archived unchanged. The AI icon was recreated from it on 2026-10-13 because the earlier sparkle-icon preview had no separately available image file. It preserves the thermal/glider concept and adds two sparkles; it is a recreated asset, not a byte-identical copy of that preview. Both icons are standalone square PNG artwork with opaque backgrounds. Platform-specific sizing/masks and native app integration remain future work.

## Scope and verification

- M1 design asset task: archive the two approved logos and both icon variants, and expose them from the central README.
- Dependencies: the selected Thermik concept, contrast corrections and explicit AI badge approved in the design conversation.
- Acceptance checks: PNGs decode successfully; dimensions, file hashes and relative links are checked; changes include only branding assets and their documentation.
- This selection does not approve screen layouts, complete M1, integrate the logos into the native app, or establish delivery of the planned AI features.
