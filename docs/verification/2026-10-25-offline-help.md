## Delivered source slice

- A versioned, bundled German [Help catalogue](../../apps/platform-lab/src/mobile/help-catalog.ts) supplies six curated entries, including a [PIC definition from EASA](https://www.easa.europa.eu/sites/default/files/dfu/Sailplane%20Rule%20Book.pdf). The displayed source role remains separate from flightbook credit. Search tolerates accents and finds title, synonyms and answer text without a service call.
- [HelpScreen](../../apps/platform-lab/src/mobile/HelpScreen.tsx) uses a searchable, category-filtered offline Help home and distinct question/answer bubbles with content date/source. Missing IDs and unmatched queries have an explicit no-answer state. Opening a source URL requires a separate tap. No AI composer, provider operation or automatic context upload was added.
- Profile, empty Flüge and backup scope open Help through the existing overlay stack. [Ordinary flight details](../../apps/platform-lab/src/mobile/FlightDetails.tsx) add a 48 dp PIC Info target and inline bubble; **Mehr erfahren** opens its full Help answer. Back from article returns to Help home, Back from Help returns to the prior Profile or flight route, preserving filters, scroll position and profile draft. The existing Statistics contributor detail still shares `FlightDetails` but does not expose the new PIC Info action; its internal route stack is unchanged.
- Populated Flüge shows one optional introductory hint on first eligible visit. Its generic dismissal is versioned and local to the installation via SecureStore; **Später** defers it, **Verstanden** records completion, and Help can replay it. The preference contains no account/flight data and is excluded from manual backup. Existing empty/offline/failed guidance under #22 remains independent.
- Profile has a global, installation-local **Kontexthilfe** setting. Off suppresses automatic hints and contextual Info/Help links, including PIC and backup scope; the manual searchable Help library stays available in Profile. The setting is independent of catalogue version and survives restart. On re-enables contextual guidance without resetting an acknowledged hint. Save failure leaves the prior state in place and is shown in Profile.
