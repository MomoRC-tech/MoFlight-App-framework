## C1 implementation and test assessment

[Projection](../../apps/platform-lab/src/mobile/flight-classification.ts) separates explicit category/launch names from unrecognized codes, missing/blank fields and contradictory aliases. Segelflugzeug, Motorsegler, explicit TMG, Motorflugzeug, Ultraleicht and Hubschrauber are display categories; they confer no licensing/book/role credit. Full launch names support Winde, F-Schlepp, Selbststart and Autoschlepp. Short W/F/E and numeric values intentionally remain unrecognized until verified.

[Filter composition](../../apps/platform-lab/src/mobile/own-flight-model.ts) adds optional category/launch constraints, independent removable tags and reset behavior to existing period/search/registration/exact-ID filters. [Statistics grouping](../../apps/platform-lab/src/mobile/statistics-overlay-model.ts) reuses unique-ID/conflicting-facts rules, deterministic known time and exact contributing identities. Unknown classification and unknown duration remain visible in separate fields. Existing callers supply selected-owner data; no new cross-owner cache/store exists.

Meaningful [regressions](../../tests/mobile/flight-classification.test.ts) cover explicit categories, Motorsegler/TMG distinction, full-word aliases, rejected codes, conflicting/blank columns, no registration/model inference, preserved original observations and v1 validator, combined filters/reset, exact group membership, unknown durations and conflicting identities. Existing card/presentation/navigation/assessment/aggregate-restore tests protect unaffected contracts. No geometry snapshots or new application dependency.
