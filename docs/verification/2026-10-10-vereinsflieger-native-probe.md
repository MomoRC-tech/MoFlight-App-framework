## Implemented slice

- Existing Expo/React Native lab adds WebView `13.16.1`, the version recommended by Expo SDK 57's primary docs on this date. Lockfile is generated by pnpm 11.25.0; no separate framework or hosted service added.
- Original HTTPS provider login runs inside the app. No password/form inspection, saved credential feature, cookie transfer or login-page extraction script. Non-incognito browser-store session reuse is attempted, not asserted as tested.
- Retrieve automatically navigates to the observed `/member/profile/flightlog.php` path and reads `tablelist_20` through an explicit page-scoped script, at most 20 visible rows. It needs no user date range. This is bounded default-list capture, not full-history retrieval or an automated Excel export.
- Plain JavaScript reader avoids bundler-dependent function serialization. Reader checks top frame, exact HTTPS provider host and personal-page path. Native handling independently checks URL/origin, request nonce, payload bounds, column uniqueness, required date/aircraft/crew/time columns and row dimensions. Changed/empty/oversized results fail explicitly; no successful empty import is inferred.
- All navigations pass an exact-URL validator. Library whitelist is `['*']` solely to prevent the library handing rejected URLs to the external OS browser before the custom validator; custom checks still permit only the two exact provider HTTPS hosts. New windows, file access, mixed content, third-party cookies and remote WebView debugging are disabled/blocked. Initial source URLs are constants. Runtime redirect/frame behavior still needs device validation.
- Successful raw captures are saved in separate private SQLite storage with unique capture IDs; earlier captures survive errors. They are not canonical imports and never modify synthetic history/backups. Captures preserve source strings, separate crew columns and candidate source references; source account identity, time basis and complete coverage are explicitly unverified.

Initial partial-workspace test failed because the existing Python reference module had not been materialized locally; fetched the unchanged reference files and reran all 16 tests successfully. Fixture check then caught local CSV CRLF normalization during materialization; restored the original canonical bytes and reran successfully. No fixture/reference source change is published to address either local setup issue.

The emulator harness adds two credential-free checkpoints: opening the isolated probe offline with no saved capture, then closing it and finding unchanged synthetic state. These checks, even when they pass, do not establish provider login/retrieval. GitHub CI rebuilds the changed app and runs the native synthetic suite; its outcome is pending at initial publication.
