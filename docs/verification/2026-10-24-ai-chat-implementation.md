## AI02 first local source-tool increment

Source baseline: `63ce09c`, the pushed AI00/AI01 implementation; this section describes the following source-tool commit linked from #74. Main owns [flight-only context admission](../../apps/platform-lab/src/ai/flight-context.ts) and [the bounded tool capability](../../apps/platform-lab/src/ai/flight-tools.ts). Luna Max implemented only [source projection](../../apps/platform-lab/src/ai/projection.ts) and its tests; main reviewed and requested additional outer source-reference/evidence binding, duplicate-source rejection and the existing library-size ceiling. The projection retains detached raw evidence only in local maps; validated upstream DTOs contain aliases/opaque references and allowed facts.

The context reader calls `OwnFlightReadPorts.service.readStored` without invoking Medical, duties or information readers, and closes the read lease before returning. Historical identity with no saved binding yields unavailable flight context, preserving general questions. Pending commands, recovery and unreadable stores yield unavailable source data. Current owner/account/store, generation and availability changes revoke the old context. Native composition of these new ports remains AI07/AI08 work; the existing app still has its previous AI placeholder.

The five tool names are implemented locally: dataset description, source-label resolution, filtered/paged flights, deterministic aggregates and supporting flight evidence. Arithmetic reuses `summarizeRealFlights`; interval coverage reuses `statisticsCoverageComplete`. Numeric totals use safe integer minutes; averages exclude unknown/invalid/conflicting durations, and unknown-only averages stay null. Exact duplicate rows count once, inconsistent duplicate identities fail closed. Source labels normalize Unicode/case/whitespace only; distinct spelling/accent labels remain separate candidates. Blank or uncaptured crew slots conservatively qualify source-name results. No person/credit/training inference is made.

Tool state is scoped to the run: opaque page tokens bind filter/limit/offset in a local map and are absent from another run's map; changing source context interrupts calls, including after an asynchronous recheck. Call IDs cannot repeat, call count is bounded, and disposal drops page/metric/source references. AI07 must supply a cryptographically random token generator, connect the current-source check and release its own attempt snapshot when finished. Answer publication still needs the coordinator's final current-context check.

The v1 contract was tightened before any deployed consumer: projected rows now include parsed source start/landing clocks (no timezone/day-offset inference), and coverage explicitly counts unknown crew and registration fields. Coverage's `totalRows` is the inspected saved dataset; `suppliedRows` is returned/aggregated rows and `omittedRows` includes rows not supplied after filtering/pagination. Unknown-date/crew/registration counts are conservative dataset-wide counts; they may prevent a complete claim even if unrelated missing rows could eventually be excluded. Period coverage is distinct from observed matching-record endpoints. Pending source issues prevent complete claims.
