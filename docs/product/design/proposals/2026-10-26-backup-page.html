Enthalten: eigene Flüge und Belege, lokale Flugbücher, Profil und unterstützte eigene Vereinsflieger-Quellen einschließlich Medical. Auch KI-Chats, Entwürfe, gespeicherte Anbieter-Kennungen früherer Anmeldungen und vorläufige Jahres-Sollstunden können enthalten sein.

Route and state contract for a later implementation

  • Profil & Einstellungen → Datensicherung → Back returns to the same Profile state. Android Back follows the same path; in the confirmation dialog it dismisses only the dialog first.
  • The page uses the existing owner-scoped backup/restore logic. Opening it triggers no provider login, data retrieval or file access. File and folder pickers remain operating-system owned.
  • Back and competing actions remain blocked during an uncancellable write. Cancellation, failure, recovery and success have distinct text states; success claims a saved backup only after verified readback.
  • Without a selected local owner, the page shows the existing explicit empty state and does not create an identity. The older flight-library format remains a separately labelled option; synthetic backup stays under Development.
  • Content width is capped on larger windows. This sketch defines only the dark master variant; light-mode acceptance waits until beta. Start, the original logo and the global palette remain unchanged.

Why this structure?

Google recommends a clear navigation hierarchy and top-bar actions for child destinations, roughly 16 dp compact-page margins and visible grouping of related content. The short confirmation dialog has a title, explanation, Cancel and confirm actions; longer backup content remains on the page. This adapts Material 3 app bars, dialogs and lists to MoFlight's existing React Native UI, without a Compose migration. See also Google's navigation patterns and content structure.

This proposal belongs to #94. It is a browser sketch with illustrative states, not approved implementation or native verification. If selected, a bounded app package would receive focused host checks and one brief dark inspection of the affected page.
